# 穿搭建议质量验证报告

**项目**：WeatherOutfitAdvisor — 基于 LLM 的天气穿搭助手
**验证日期**：2026-10-14
**模型**：DeepSeek V4.1 Flash
**Agent 框架**：LangChain 1.4.4 `create_agent` + ReAct 工具调用
**底层依赖**：langchain-core 1.6.9、langgraph 1.2.14、langchain-openai 1.7.0
**评估方法**：CheckEval 风格 checklist 评估（二元问题）

---

## 1. 验证目标

本报告旨在系统性评估 LLM 生成的穿搭建议质量，回答以下问题：

1. 建议的**温度逻辑**是否与真实气温匹配？
2. 建议是否**分层完整**（上装/下装/鞋履/外套/配饰）？
3. 是否给出**具体材质**，而非泛泛而谈？
4. 是否**贴合场景**（通勤/约会/运动/旅游/海边）？
5. 是否包含**特殊提醒**（防晒/防雨/温差/干燥）？
6. 是否提供**配色建议**？

---

## 2. 验证方法

### 2.1 Checklist 设计

采用 CheckEval（EMNLP 2025）提出的**分解式二元问题**替代 Likert 量表打分，让评估更可靠、可解释。每条建议按以下六个维度逐项打分（是/否）：

| 维度 | 评估问题 |
|------|---------|
| **温度合理性** | 建议的服装厚度是否与温度区间匹配？ |
| **分层完整性** | 是否包含上装、下装、鞋履、外套/备用？ |
| **材质具体性** | 是否提到了具体材质（如棉麻、聚酯纤维、摇粒绒）？ |
| **场景贴合** | 建议是否符合场景（通勤/约会/运动/旅游/海边）？ |
| **特殊提醒** | 是否提到了防晒/防雨/温差/干燥等提醒？ |
| **配色建议** | 是否给出了配色方案？ |

### 2.2 验证用例设计

覆盖 **5 种气候带 × 5 种场景**，避免单一场景造成的评估偏差：

| ID | 城市 | 场景 | 气候类型 | 关键期望 |
|----|------|------|---------|---------|
| 1 | 广州 | 通勤 | 南方湿热 | 透气、防晒、速干 |
| 2 | 哈尔滨 | 旅游 | 北方干冷 | 羽绒、保暖、防风 |
| 3 | 上海 | 约会 | 南方湿冷/过渡季 | 风衣、衬衫、层次 |
| 4 | 北京 | 运动 | 北方干燥 | 速干、透气、运动 |
| 5 | 三亚 | 海边 | 热带 | 防晒、透气、浅色 |

用例数据保存在 `data/validation_cases.json`，原始输出保存在 `data/validation_outputs.json`。

### 3.2 分项质量观察

#### ✅ 温度逻辑准确性

各用例建议均体现了对温度区间的正确理解：

- **广州（23~30℃）**：建议短袖 + 薄外套，明确指出"早晚 23℃ 偏凉，午间 30℃ 脱掉收进托特包"
- **哈尔滨（1~11℃）**：识别昼夜温差 10℃，建议"分层穿脱"，早晚强调"接近冰点"
- **上海（19~24℃）**：识别温差仅 5℃，建议"薄外套即可"
- **北京（12~24℃）**：识别温差 12℃ 且湿度仅 18%，区分"晨跑/傍晚运动"与"午间运动"的不同着装
- **三亚（23~32℃）**：识别"典型热带海边天气：白天暴晒闷热，早晚微凉"

#### ✅ 材质具体性

建议中给出了具体的**纤维类型和结构描述**，而非笼统的"穿毛衣"：

| 用例 | 材质建议示例 |
|------|-------------|
| 广州 | 精梳棉/棉+亚麻混纺、真丝/莫代尔混纺、聚酯混纺/天丝 |
| 哈尔滨 | 莫代尔/美利奴羊毛打底、摇粒绒半拉链抓绒衣、三合一冲锋衣 |
| 上海 | 薄针织长袖、牛津纺衬衫、细坑条打底 |
| 北京 | 聚酯纤维/锦纶混纺速干衣、压缩内裤、毛巾底速干运动袜 |
| 三亚 | 棉麻/速干料、UPF50+ 防晒衫、阔腿亚麻短裤 |

#### ✅ 场景化洞察

建议中出现了超出"基础推荐"的**场景化细节**：

- **哈尔滨**："中午的太阳骗人，体感容易被'中午的太阳'骗到，分层穿脱是核心"
- **哈尔滨**："江风从领口灌进来最难受；羊毛围巾比化纤保暖且不闷"
- **北京**："运动场景核心矛盾：早晚偏凉、午后偏热 + 干燥"
- **北京**："运动后立刻擦汗加外套，别穿湿衣在户外吹风"
- **广州**："地铁与办公室空调通常 26℃ 以下，早晚 23℃ 也偏凉"
- **三亚**："别穿白球鞋——进沙后基本报废"

这些洞察体现了模型对**真实使用场景**的理解，而非简单的天气-服装映射。

#### ✅ 特殊提醒覆盖

五个用例均给出了针对性的特殊提醒，且与当日天气条件强关联：

| 用例 | 提醒类型 | 具体内容 |
|------|---------|---------|
| 广州 | 防晒 + 防闷汗 | UV 7，建议 SPF30+/PA+++；湿度 74%，建议速干面料 |
| 哈尔滨 | 保暖 + 干燥 | 帽子+围巾+手套三件套；湿度 38%，带护手霜 |
| 上海 | 温差 + 约会细节 | 早晚微凉带外套；"鞋面干净、衣物无褶皱比单品贵价更重要" |
| 北京 | 补水 + 防晒 | 湿度 18%，运动前后小口补水；UV 4，建议 SPF30+ |
| 三亚 | 防晒 + 防蚊 | UV 8，建议 SPF50+/PA++++，每 2 小时补涂；傍晚驱蚊 |

#### ✅ 配色建议

所有用例均给出配色方案，且与**气候 + 场景 + 视觉美学**结合：

- **广州（湿热）**：清爽浅色系，白 + 浅蓝 + 米/燕麦，"浅色反光、视觉降温"
- **哈尔滨（干冷）**：燕麦白 / 米杏 / 炭灰，配"酒红、墨绿或姜黄跳色"
- **上海（约会）**：低饱和温柔色系，米白 + 燕麦 + 浅卡其
- **北京（运动）**：黑 / 深灰 / 藏蓝 + 荧光绿/亮橙点缀，"晴天户外更醒目、安全性高"
- **三亚（海边）**：白 / 米沙色 / 浅蓝，"与海水蓝、沙滩形成干净对比"

## 4. 典型输出样本

### 样本 1：广州 / 通勤（南方湿热）

> **天气概览**：广州明天（10月15日）晴，23~30℃，北风1-3级，湿度74%，紫外线指数7（偏高），降水概率0%。特点：昼夜温差7℃、午间晒且闷、无雨但紫外线强。通勤重点=透气+防晒+空调房备用层。
>
> **上装**：精梳棉或棉+亚麻混纺短袖T恤，或真丝/莫代尔混纺短袖衬衫（垂顺、不贴汗）。领型选翻领或小立领，比圆领更撑得住通勤的正式感。
>
> **下装**：薄款直筒西裤或九分阔腿裤（聚酯混纺/天丝面料，垂感好、抗皱、不粘腿）。
>
> **鞋履**：透气乐福鞋、小白鞋或低跟穆勒鞋，鞋面选网眼或皮质打孔款。
>
> **外套/备用**：轻薄西装外套（无里衬）或防晒开衫。硬性理由：地铁与办公室空调通常26℃以下，早晚23℃也偏凉，一件薄外套能同时解决温差+空调两个问题。

### 样本 2：哈尔滨 / 旅游（北方干冷）

> **天气概览**：哈尔滨·10月15日多云，1~11℃，西风1-3级，湿度38%，降水概率0%，紫外线指数2（弱）。关键点：昼夜温差10℃，早晚接近冰点、午后偏凉；空气干燥、无雨、日照温和。哈尔滨十月已进入深秋末尾，体感容易被"中午的太阳"骗到，分层穿脱是核心。
>
> **上装**：第一层莫代尔或美利奴羊毛薄款长袖打底T恤（贴身排汗，别选纯棉——出汗后贴背会发凉）；第二层摇粒绒半拉链抓绒衣或薄款羽绒内胆，厚度中等即可。
>
> **外套/备用**：主外套轻薄羽绒服或三合一冲锋衣（防风壳+抓绒内胆），这是哈尔滨秋季旅游的最优解。
>
> **提醒**：早晚体感接近0℃，帽子+围巾+手套三件套别省，尤其围巾——江风从领口灌进来最难受；羊毛围巾比化纤保暖且不闷。

## 5. 局限性

1. **样本规模较小**：仅 5 条用例，覆盖 5 种气候带，但每个气候带只有 1 条样本。
2. **缺乏人类评估对照**：当前评估为单人 checklist 打分，未与多名标注者做一致性分析。
3. **未覆盖极端天气**：暴雨、暴雪、台风等极端场景未纳入验证。
4. **rating indeterminacy 问题**：穿搭建议天然存在多个合理解（如"15℃通勤"既可以薄风衣+针织，也可以夹克+卫衣）。当前 checklist 用"是/否"评估，未捕捉这种多元合理性。
5. **LLM 评估偏差**：如使用 LLM-as-Judge 进行自动评分，需注意其对长度、格式、位置的敏感性（参考 FairJudge, ICML 2026）。

## 6. 未来工作

- **扩大验证样本**：每个气候带至少 3 条用例，覆盖更多城市与季节。
- **引入多人标注**：邀请 3-5 人独立打分，计算与 LLM 评估的一致性（Cohen's κ）。
- **加入 LLM-as-Judge 自动评分**：用 checklist 提示 DeepSeek 自动打分，与人工结果对比。
- **引入材质-价格结构化数据**：将建议从"材质类型"细化到"具体单品 + 价格区间"，验证专业性提升。
- **评估 rating indeterminacy 影响**：设计允许多答案的评估框架，而非强制单一最优。

---

## 7. 结论

在 5 个覆盖不同气候带和场景的验证用例上，本系统生成的穿搭建议在**温度合理性、分层完整性、材质具体性、场景贴合、特殊提醒、配色建议**六个维度全部通过，通过率 **30/30 = 100%**。

建议中出现了多处以真实场景为基础的洞察（如哈尔滨"中午的太阳骗人"、北京"运动场景核心矛盾"、广州"地铁空调26℃以下"），说明模型在结合天气数据和场景上下文方面表现良好。

当前验证的局限主要在于**样本规模**和**缺乏多人标注对照**，后续将扩大验证范围并引入 LLM-as-Judge 自动评估。
